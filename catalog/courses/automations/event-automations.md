## What this lesson covers

- Run when something happens, not when a clock fires
- Built-in GitHub events vs custom webhooks (Linear, Slack, Stripe)
- Typical jobs: PR opened, issue labeled, ready for review
- Register webhook secrets yourself; do not paste them into the agent

## Outline

1. GitHub events you can filter
2. Custom webhook two-phase setup
3. Example: review when a PR is ready
4. Example: triage when an issue is labeled
