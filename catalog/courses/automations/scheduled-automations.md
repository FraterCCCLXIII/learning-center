## What this lesson covers

- Cron-style runs: daily standups, weekly summaries, Monday dependency checks
- Timezone and LLM profile on the automation
- Create from a conversation or from Automate
- Enable, disable, and inspect run history

## Outline

1. Name, schedule, timezone, prompt
2. Create via the Automation skill
3. Pick the LLM profile future runs use
4. Read the last run before you trust it

## Try this

Create a weekly “repo health” automation that opens a draft PR or posts a short report. Keep it disabled until you have reviewed one dry run.
