# From chats to always-on workflows

_Stub article._ Outline only — full draft later.

**Audience:** Individual developers and companies  
**Sources:** [Introducing Agent Canvas](https://www.openhands.dev/blog/introducing-agent-canvas) · [Automations Overview](https://docs.openhands.dev/openhands/usage/automations/overview)

## What this lesson covers

- Chats are for work you want to steer
- Automations are for work you want to repeat
- Examples: dependency updates, repo reports, docs drift, issue sweeps
- Automations run on a backend — they need that backend to stay up

## Outline

1. One-off conversation vs scheduled run
2. What the automation inherits (LLM, secrets, MCP)
3. Prompt-based vs plugin-based automations
4. Review the output; automation is not unsupervised
