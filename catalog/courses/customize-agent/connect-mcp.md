_Stub article._ Outline only — full draft later.

**Audience:** Individual developers

## What this lesson covers

- MCP gives the agent tools from GitHub, Slack, and other servers
- Marketplace entries vs a custom command
- Secrets stay in settings, not in the prompt
- Test the connection before you rely on it in an automation

## Outline

1. Open the MCP page in Canvas
2. Install a catalog server (GitHub or Slack)
3. Store the API key as a secret
4. Ask the agent to use that tool once

## Try this

Connect one MCP server you already have credentials for. Ask the agent to list something harmless (open issues, recent Slack channel names) and check the tool call.
