## What this lesson covers

- A workspace is the folder or repo the agent can read and write
- Local folder vs connected GitHub / GitLab repository
- Why the agent should work in one project at a time
- How Canvas remembers workspaces you use often

## Outline

1. What “workspace” means in Canvas
2. Attach a local folder
3. Attach a git repository
4. Start a conversation against that workspace

## Try this

Open **New Chat**, pick a small repo you own, and ask the agent to summarize the README. Confirm the Files tab shows that project.
