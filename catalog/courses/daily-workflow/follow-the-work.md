# Follow files, terminal, and browser

_Stub article._ Outline only — full draft later.

**Audience:** Individual developers  
**Sources:** [Agent Canvas overview](https://docs.openhands.dev/openhands/usage/agent-canvas/overview) · [Key Features](https://docs.openhands.dev/openhands/usage/key-features)

## What this lesson covers

- Files and diffs: what changed
- Terminal: commands the agent ran
- Browser: pages it opened
- When to pause, edit, or take over

## Outline

1. Read the change list before you merge anything
2. Check terminal output for failed tests
3. Use the browser tab when the task is UI
4. Leave a follow-up message instead of restarting

## Try this

Ask the agent to add a failing test, then watch Files and Terminal. Stop it if it starts editing unrelated files.
