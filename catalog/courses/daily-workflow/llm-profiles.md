# Save and switch LLM profiles

_Stub article._ Outline only — full draft later.

**Audience:** Individual developers  
**Sources:** [Manage LLM Profiles](https://docs.openhands.dev/openhands/usage/agent-canvas/llm-profiles) · [Language Model Settings](https://docs.openhands.dev/openhands/usage/settings/llm-settings)

## What this lesson covers

- Profiles store model, base URL, and keys
- Use a cheaper model for drafts, a stronger one for review
- Switch mid-conversation when the task changes
- Local models vs hosted providers

## Outline

1. Create a default profile
2. Add a second profile for a different model
3. Switch from the conversation chrome
4. Keep keys in settings, not in the prompt

## Try this

Save two profiles. Run the same small task on both and note latency and quality — not just cost.
