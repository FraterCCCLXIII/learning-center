# Measure quality and scale

_Stub article._ Outline only — full draft later.

**Audience:** Companies  
**Sources:** [OpenHands for Enterprise](https://www.openhands.dev/enterprise) · [Monitoring and Improving Skills](https://docs.openhands.dev/overview/skills/monitoring)

## What this lesson covers

- Track merge rate and suggestion acceptance per workflow
- Custom metrics on a skill or automation
- Feedback from production back into the prompt or skill
- Scale the workflows that pay off; turn off the ones that do not

## Outline

1. What “good” means for a PR review vs a docs bot
2. Log runs, outcomes, and human overrides
3. Improve the skill, not just the model
4. Repeat the loop on the next SDLC phase

## Try this

Pick one automation. For the last ten runs, note: merged as-is, edited, or discarded. If fewer than half were useful, rewrite the prompt before you add more triggers.
