## What this lesson covers

- Solo: morning CI review, implement, pre-commit review, docs
- Small team: one person implements, agent reviews, another human approves
- Enterprise: platform team sets policy; feature teams stay inside it
- Slack summaries and issue creation as the communication layer

## Outline

1. Daily loop for one developer
2. Two-to-ten person review loop
3. Platform vs feature-team split
4. What stays a human decision at each size
