## What this lesson covers

- Install Canvas on your machine
- Choose OpenHands or an ACP agent (Claude Code, Codex, Gemini CLI)
- Connect a backend (local first)
- Add an LLM key or profile
- Confirm you can start a conversation

## Outline

1. Install and launch Agent Canvas
2. Pick an agent
3. Add or select a backend
4. Save an LLM profile
5. Launch a hello-world task

## Try this

Finish onboarding until you can send a message in a new chat. If Canvas asks for a key or backend, complete that screen before the next lesson.
